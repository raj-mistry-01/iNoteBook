# 🧠 iNoteBook

**iNoteBook** is a modern full-stack note-taking application built with **React.js** on the frontend and **Express.js** on the backend. It allows users to securely manage their personal notes with authentication and a Recycle Bin feature.

---

## 🚀 Features

### ✨ Core Features
- Create, Read, Update & Delete (CRUD) notes
- Users can download their notes as a notebook pdf
- Recycle Bin (soft delete & restore notes)
- JWT-based authentication
- Secure user-specific notes
- Clean and responsive UI

### 🔐 Security
- JSON Web Token (JWT) authentication
- Password hashing for secure storage
- Protected backend routes

### ⚙️ Tech Stack
- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT  
- **UI:** React + CSS / Bootstrap

## 🧩 Feature Details

### ✍️ Notes Management
- Add new notes
- Edit existing notes
- Delete notes (moved to Recycle Bin)
- Notes are user-specific

### ♻️ Recycle Bin
- Deleted notes are stored
- Restore deleted notes
- Permanently delete notes if required

### 📥 Notebook Download
- Download all notes as a single notebook pdf

### 🔐 Authentication Flow
- User signup
- User login
- JWT token stored on client
- Protected API routes
